# Hands-on Activity 4.1: Stacks

## Description
This activity explores stacks, a linear data structure that follows the Last In, First Out (LIFO) principle. It focuses on fundamental stack operations and their implementation using C++.

## Files Included
- `.cpp` – C++ source code containing the program implementation
- `.h` – Header file containing declarations and related components
- `.pdf` – Activity documentation and requirements
