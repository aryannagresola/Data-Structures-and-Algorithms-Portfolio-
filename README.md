# Data Structures and Algorithms Portfolio

## About This Repository

Welcome to my **Data Structures and Algorithms Portfolio**! This repository contains the compilation of my hands-on activities and programming exercises for the subject **CPE010 - Data Structures and Algorithms**.

The repository showcases my progress and understanding of fundamental data structures, algorithmic techniques, and problem-solving using **C++ programming**.

Each activity folder contains the corresponding C++ source code (`.cpp`) and PDF documentation (`.pdf`).
