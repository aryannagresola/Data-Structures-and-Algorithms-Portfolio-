# Hands-on Activity 13.1: Parallel Algorithms and Multithreading

## Description
This activity explores parallel algorithms and multithreading in C++. It focuses on dividing computational tasks into smaller operations that can be executed concurrently using multiple threads. It demonstrates how parallel processing can improve program performance, optimize resource utilization, and support efficient execution of computational tasks.

## Files Included
- `.cpp` – C++ source code containing the program implementation
- `.pdf` – Activity documentation and requirements
