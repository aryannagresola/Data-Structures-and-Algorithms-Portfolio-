# Hands-on Activity 5.1: Queues

## Description
This activity introduces queues as a linear data structure that follows the First In, First Out (FIFO) principle. It demonstrates how elements are added and removed based on their order of arrival.

## Files Included
- `.cpp` – C++ source code containing the program implementation
- `.h` – Header file containing declarations and related components
- `.pdf` – Activity documentation and requirements
