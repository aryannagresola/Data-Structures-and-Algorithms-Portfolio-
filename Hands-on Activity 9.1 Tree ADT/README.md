# Hands-on Activity 9.1: Tree ADT

## Description
This activity introduces the Tree Abstract Data Type (ADT), a non-linear data structure used to represent hierarchical relationships. It explores tree components, node relationships, and fundamental operations for managing tree structures.

## Files Included
- `.cpp` – C++ source code containing the program implementation
- `.h` – Header file containing declarations and related components
- `.pdf` – Activity documentation and requirements
